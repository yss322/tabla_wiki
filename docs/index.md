# Tabla Beginner Lessons

Welcome! This site holds the **beginner-level tabla curriculum** — four
semesters of practice exercises, kaaydas, relas, and tukdas. Each lesson lists
its **bols** (spoken syllables) and, where available, a **demonstration video**.

Use the navigation on the left (or the menu button on mobile) to browse by
semester, and the 🔍 search box to jump to any composition.

---

## Tabla playing instructions

1. Relax hand
2. Shoulder posture correction
3. Recitation practice with hand clap
4. Left-hand fingers should touch the edge
5. *Tere kete* should stay within the black **gaab** area of the tabla
6. Beginners: only straight *tete* — no reverse *tete*
7. No more than **3 paltas** in one hour

---

## Class instructions (for teachers)

- Check that the student has a tabla set.
- Confirm each student has registered / paid (screenshot in the group channel).
- Ask students to bring a composition notebook for notes.
- Maximum class size: **8 students**.
- First check each student's tabla level individually, then practise as a
  group — but have each student also play individually in class.
